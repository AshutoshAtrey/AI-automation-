
# Universal AI Form Assistant

An AI-powered assistant designed to help users
complete forms and questionnaires across websites.

## Features

- Detect form fields
- Read and understand questions
- AI-powered answer suggestions
- Automatically fill form fields
- Support multiple-page questionnaires
- User approval before submission

## Compatibility

Designed for different websites and form layouts.

## Platform

Browser-based assistant.

## AI Integration

AI-powered question understanding and answer generation.

## Status

Development in progress.
